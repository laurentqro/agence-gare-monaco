## Phase 4: Immotoolbox Sync
### Task 11: API Client & Sync Service ✅
Implemented the Immotoolbox API client and sync service with TDD (34 tests):
- **ImmotoolboxClient** (`app/services/immotoolbox_client.rb`): HTTP client for Immotoolbox REST API using Net::HTTP. Auth via `X-AUTH-TOKEN` header. Methods: `fetch_districts`, `fetch_buildings`, `fetch_properties(page:)`, `fetch_all_properties` (auto-paginating), `fetch_property(id)`, `fetch_images(property_id:)`, `fetch_texts(property_id:)`. Custom `ApiError` for HTTP errors and network timeouts.
- **ImmotoolboxSync** (`app/services/immotoolbox_sync.rb`): Sync service that imports districts, buildings, and properties from the API. Key behaviors:
  - `sync_districts`: creates/updates districts by `immotoolbox_id`, auto-generates slugs
  - `sync_buildings`: creates/updates buildings, links to districts via `immotoolbox_id`
  - `sync_properties`: creates/updates properties with full field mapping (pricing, location, dimensions, media URLs), fetches multilingual texts (title/description per language), fetches and syncs property images (CDN URLs at all sizes), skips `manually_edited` properties, unpublishes synced properties no longer in API response (preserves non-synced properties)
  - `sync_all`: runs districts → buildings → properties in order, returns summary statistics (created/updated/unpublished/skipped counts)
- **Rake task** (`lib/tasks/immotoolbox.rake`): `immotoolbox:sync` — reads API token from `IMMOTOOLBOX_API_TOKEN` env var or Rails credentials, runs full sync, prints summary
- Added `webmock` gem for HTTP request stubbing in tests
- 317 total tests passing (283 existing + 34 new)

### Task 12: Scheduled Sync Job ✅
Implemented the scheduled Immotoolbox sync job with TDD (9 tests):
- **ImmotoolboxSyncJob** (`app/jobs/immotoolbox_sync_job.rb`): ActiveJob that runs the full Immotoolbox sync. Reads API token from `IMMOTOOLBOX_API_TOKEN` env var with fallback to Rails credentials (`credentials.immotoolbox.api_token`). Logs sync results (districts/buildings/properties created/updated/unpublished/skipped). Skips gracefully with warning when no API token is available.
- **Retry handling**: Retries on `ImmotoolboxClient::ApiError` and `Net::OpenTimeout` with polynomial backoff, up to 5 attempts each.
- **Recurring schedule** (`config/recurring.yml`): Configured to run daily at 6am in production via Solid Queue's recurring job scheduler.
- 326 total tests passing (317 existing + 9 new)

### Task 15: Legacy URL Redirects ✅
Implemented all legacy URL redirects (301) for the 3 existing languages (FR, EN, IT) with TDD (32 tests):
- **LegacyRedirectsController** (`app/controllers/legacy_redirects_controller.rb`): dedicated controller handling all legacy URL patterns. Looks up properties by `immotoolbox_id` to generate new URLs with slugs. Returns 410 Gone for missing/unpublished properties.
- **French legacy routes**: `/fr/location/monaco` → `/fr/locations/monaco`, `/fr/bien/{id}` → `/fr/biens/{id}-{slug}`, `/fr/bien-off-market/{id}` → property detail or 410, `/fr/pdf-download/{id}.pdf` → property detail, `/fr/pdf-download-nologo/{id}.pdf` → property detail, `/fr/posts/{category}/` → `/fr/articles/{category-slug}`, `/fr/article/{id}/{slug}/` → `/fr/articles/{slug}`, `/fr/post/{id}/{slug}` → `/fr/articles/{slug}`, `/fr/recherche/{location}` → district page or `/fr/ventes/monaco`
- **English legacy routes**: `/en/rental/monaco` → `/en/rentals/monaco`, `/en/property/{id}` → `/en/properties/{id}-{slug}`, `/en/properties-off-market/sale` → `/en/sales/monaco`, `/en/properties-off-market/rental` → `/en/rentals/monaco`, `/en/news` → `/en/articles`, `/en/article/{id}/{slug}` → `/en/articles/{slug}`
- **Italian legacy routes**: `/it/affitto/monaco` → `/it/affitti/monaco`, `/it/immobile/{id}` → `/it/immobili/{id}-{slug}`
- **Trailing slash handling**: `TrailingSlashRedirector` Rack middleware (`lib/trailing_slash_redirector.rb`) at top of middleware stack. All paths with trailing slashes (except root `/`) get 301 redirected to the version without trailing slash. Consistent URL format across the entire site.
- **Edge cases**: unpublished properties return 410, missing immotoolbox_id returns 410, search with matching district slug redirects to district page, search without match redirects to sales monaco
